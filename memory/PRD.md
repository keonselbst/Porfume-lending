# ТИШЬ — независимый парфюмерный дом

## Исходный запрос
«создай роскошный, мега красивый, современный, минималистичный лендинг сайт какой-нибудь парфюмерной в России. дизайн и стиль сделай как в презентациях Apple в 2025-2026 ГОДАХ.»

## Подтверждённые предпочтения
- Придумать российский нишевый бренд.
- Изучение ароматов, заявка на персональный подбор, знакомство с брендом, переход во внешний магазин.
- Светлое, воздушное оформление, стекло и серебро.
- Дополнительный запрос пользователя: Awwwards Site-of-the-Day уровень; выразительный кинетический hero, masked line-by-line reveal; продуманная предметная фотография; нумерованные главы манифеста; медленная редакционная бегущая строка; Framer Motion и Lenis, тонкий параллакс.
- Собственные подробные дизайн-указания пользователя использованы непосредственно, без вызова дизайн-агента.

## Концепция
ТИШЬ. «Тишина. Во флаконе.» Три состояния: Воздух, Кожа, Лес. Приглушённое серебро, молочно-белая основа, природные оливковые полутона, Manrope и Cormorant Garamond italic. Придуманный бренд представлен как первая коллекция в предзапуске. Не заявлять о реальных продажах или существующем производителе.

## Архитектура
- React 19 / CRA + CRACO; компоненты в frontend/src/components/brand.
- Framer Motion 11, Lenis 1.3.26; адаптивность, prefers-reduced-motion.
- Shadcn/Radix Dialog, Button, Input, Checkbox. Фокус, Escape, вложенный диалог приватности.
- FastAPI + Motor + MongoDB. База из неизменённых MONGO_URL/DB_NAME.
- Frontend запросы только через REACT_APP_BACKEND_URL.
- Авторизация отсутствует и не запрошена. Публичного чтения заявок нет.
- Продукты из backend/collection.py, идемпотентно записываются в fragrances при старте. Заявки в leads.

## API
- GET /api/ — health.
- GET /api/collection — 3 аромата и необязательный shop_url.
- GET /api/fragrances/{id} — описание, цена, ноты; 404 при неизвестном id.
- POST /api/leads — имя, телефон/email, пожелания, аромат, intent selection/availability, обязательное согласие. Ответ 201 с UUID; валидация и лимит 4 заявки на контакт за 10 минут.
- Mongo _id исключён из публичных ответов; UTC ISO timestamps.
- Необязательный backend SHOP_URL включает HTTPS-ссылку на внешний магазин. Сейчас не задан: вместо фиктивной покупки доступна реальная заявка о старте продаж.

## Реализовано
1. Главный экран с построчным раскрытием текста, реакцией изображения на курсор, scroll-parallax, горячей точкой флакона, CTA.
2. Главы: философия, коллекция, истоки. Бегущая строка, плавное появление секций.
3. Коллекция 3 ароматов, полноразмерные карточки с пирамидой нот и ценой в рублях.
4. Рабочая форма подбора/интереса к запуску; сохранение в MongoDB; состояния загрузки, ошибок и успешной заявки с номером.
5. Русскоязычная информация о данных; сохранение полей при открытии приватности или сетевой ошибке.
6. Мобильное меню, адаптивность 375/390/768/1366/1920, семантика, alt, data-testid, keyboard focus.
7. Русские title/meta, favicon, локально оптимизированные WebP.
8. Фотореалистичные изображения выдуманного продукта созданы image_generation_tool; лес — фотография Unsplash. Это не фотографии реального продаваемого товара.

## Проверки
- Успешная production-сборка.
- /app/backend/tests/test_brand_api.py — 15/15 pass: контракты, валидация, MongoDB persistence, rate limiting.
- /app/test_reports/iteration_1.json — исходный отчёт testing_agent.
- Проверены основная навигация, модальные окна, отправка, ошибки сети, Escape/focus trap, согласие, адаптивность, отсутствие горизонтального overflow.
- Исправлены все замечания: noValidate + единая JS-валидация показывают inline ошибки пустых/коротких полей; сняты двойные scroll-offsets.
- Self-retest после исправления: все сообщения формы видны; верх collection y=0.328px; возврат наверх после диалога; reduced-motion hero виден.
- Ранний self-test force-click сразу после закрытия диалога попал на ещё закрывающийся overlay; повтор с ожиданием завершения 200ms exit подтвердил отсутствие дефекта навигации.
